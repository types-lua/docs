## 快速开始

```bash
go build -o tlua ./cmd/tlua
./tlua init
./tlua check --format=json
./tlua build
./tlua run --check main.tl
```

```lua
type Point = { x: number, y: number }
local function dist(a: Point, b: Point): number
  local dx: number = a.x - b.x
  local dy: number = a.y - b.y
  return dx * dx + dy * dy
end
local p: Point = { x = 1, y = 2 }
print(dist(p, { x = 4, y = 6 }))
```

## 规则速记

- 合法 Lua 5.4 即合法 TypeLua；`type`/`class`/`import`/`defer`/`await`/`spawn`/`select`/`async`/`macro` 均为上下文关键字。
- `strictNilChecks` 默认开：用 `==nil`/`~=nil`、`type(x)==`、`=="lit"`、真值、成员路径窄化。
- `interface` 结构兼容，类实例名义兼容；`super(...)` 只在派生构造器且在 `self` 之前。
- `import N from "p"` 是带类型推断的 `require` 糖；`require("ffi")` 仅在 `require` 未被遮蔽时有精确类型。
- `defer f()` 只接受调用，函数退出 LIFO 运行；`errdefer` 仅在同一函数显式 `error()` 时触发。
- 并发是单线程 CSP：`await`/`select` 在 `async` 外报错（`TL3801`/`TL3802`）；同步调用阻塞原语报 `TL3805`。
- FFI/`.so` 需 `--target 5.1` + `--lua luajit`；`ffi.cdef` 不透明，手写 `as CLib`；`.d.tl` 只检查不发射。
- JSON 诊断：`{file,line,column,endLine,endColumn,severity,code,category,message}`；`code` 稳定。
